# 人類要塞：修改建議

> 這是建議，不是規定。每一項都寫了為什麼、改哪裡、大概多少工，要不要做、怎麼做由你決定。全部只動 `levels/fort/`，不用碰共用檔案。

## 為什麼要改

試玩的人說五個大關「像五款不同的遊戲」。我們討論後覺得斷點主要不在玩法，而在戰局的外框：大關名、星星怎麼算、目標卡、結算、開場字卡，每座島各做各的。這份只談這些外框。

**不用改的**：大砲、炮塔、梯子、寶箱、自爆農夫、第三人稱幽靈視角、過關後走東門接下一關，全部保留。世界地圖那邊（南北分區、全部用★顯示、破關拿一根紫色羽毛、破關過場）由我們做。

**先說好消息**：我們讀了程式，很多已經做好了，比我們原本以為的多：
- 第一次進關自動跳共用的圖解教學，看過就記在存檔（`fort_battle.gd:3644`、`:4075`）。
- 進場鏡頭三段，其中兩段是俯瞰全場，上面有中文紙片寫關名和目標（`:4303` 起）。Tab 俯看也接了共用的 `view_toggle.gd`（`:1193`）。
- 輸了 1.6 秒後會切到共用的晚餐畫面，有 R／M（`:1007`、`:3896`）。截圖 fort_N_b_end 只拍到切換前那一刻。
- 過關已經寫進共用存檔 `Progress.mark_cleared("fort/%d")`（`:986`），地圖本來就知道哪幾關過了。`fort_progress.gd` 的 `mark_fort_stage()` 只給 `fort_world.gd:110` 挑預設小關用，不用動。

所以真正缺的是：地名、三顆星、目標卡、過關卡。

## 逐項說明

### 1. 大關名改地名

現況：`TITLE := "人類要塞"`，地圖島牌和進場鏡頭第一段的副標（`fort_world.gd:903`）都是這個。

建議：島取一個地名，例如「紫霞堡」（跟紫色羽毛對得上）、「暮岩島」、「砲台嶼」。城門上的招牌（`fort_world.gd:561`）可以繼續寫「人類要塞」：島叫一個名字，島上那座建築叫要塞，很自然。三個小關名（學大砲、三座炮塔、指揮官的院子）已經很好，不用改。

### 2. 三顆星

現況：地圖用 `scripts/level_select.gd:1541` 的 `_star_table()` 讀星星：載入 `chapter.gd` 裡 `STARS_SCRIPT` 指的腳本，讀它的 `static var best_stars`（`{小關場景路徑: {條件 id: true}}`），每小關最多算 3 顆。要塞沒有這張表，所以地圖只能用旗子算過關數。

建議的條件（依現在的機制，條件 id 自己取）：

| 小關 | ★1 | ★2 | ★3 |
|---|---|---|---|
| 1 學大砲 | 拿下炮塔、打倒兩個農夫 | 用大砲把家豪射上炮塔（`_land_cannon()` 落在塔頂那段，`:2794`） | 讓佔領的炮塔轟倒一個農夫（`_explode_shell()`，`side` 不是 enemy 時打倒人，`:2976-2986`） |
| 2 三座炮塔 | 拿下三座炮塔 | 三座用三種方法拿：巨石撞倒（`_topple()` `:2077`）、爬梯子（`_capture_tower()` `:3057`）、大砲射上去 | 家豪沒被砲彈打到（`hit_spots` 是空的，`:2991`） |
| 3 指揮官的院子 | 打倒指揮官 | 讓自爆農夫炸倒別的農夫（`_bomb_explode()` `:2368-2378`） | 沒開寶箱就過關（`_tick_chests()` `:2595`） |

為什麼這樣挑：★1 就是現在的過關條件（`_step()` 裡 `:1654` 那一行），★2 是「這關想教的那一招」，★3 是高手挑戰。第 1 小關家豪只有一顆心，所以不用「沒受傷」當條件。每座塔都有梯子、都在大砲射程內，所以第 2 小關的「三種方法」是真的要選，不是自動達成。紀錄會累積，不同條件可以分幾次拿（跟冰雪島一樣）。

做法：`fort_battle.gd` 不是共用的 `battle_base`，但森林那四個函式可以照搬（`levels/forest/forest_battle.gd:39-42`、`:851-902`、`:973-978`）：
1. 加 `static var best_stars := {}`、`var _done := {}`。
2. `_objectives()` 依 `world.stage` 回傳三條 `[{id, text}]`；達成時叫 `_mark_goal(id)`。
3. `reset()`（`:865`）清掉 `_done`；`_end()`（`:978`）贏的時候把 `_done` 寫進 `best_stars`。
4. `chapter.gd` 加 `const STARS_SCRIPT := "res://levels/fort/fort_battle.gd"`。

一個小地方：表的 key 用 `"res://levels/fort/stage_%d/stage.tscn" % world.stage` 組，不要用 `get_parent().scene_file_path`。直接開 `fort.tscn` 測試時，後者會變成 `fort.tscn`，地圖對不上。另外星星要回到地圖才會存進存檔（地圖的 `_sync_stars()`），每座島都一樣。

### 3. 目標卡

現況：左上角是空的。目標只在進場鏡頭的紙片出現一次（`fort_world.gd:119` 的 `stage_goal`）。右上角是「農夫 2/2」「敵方炮塔 1/1」（截圖 fort_1_a_prepare）。

建議：`_build_hud()` 加一張 `UIStyle.paper()` 紙卡放左上角，標題「目標」，三行「☆ 條件」，做到變金色。照抄森林的 `_build_goals()`／`_refresh_goals()`（`forest_battle.gd:904-954`）。右上角的計數保留。

### 4. 過關卡

現況：
- `_show_summary()`（`:4055`）還是農場範例的字：「攻下農場大門！這場是你偷偷扳回來的。」＋歷次嘗試。
- 第 1、2 小關這張框只停 2.4 秒（`EXIT_WAIT`，`:246`），就自動開門走進下一關，這段時間 R 被擋掉（`:1131-1133`）。想回頭拿星星只能回地圖再進來。
- 第 3 小關會一直停在這張框上。

冰雪島、丹穴山的過關卡是：「★★☆（2/3）」＋三條☑／☐＋新拿到的標「新！」＋沒拿到的一行提示＋「Enter 下一關」（`levels/ice/rescue_battle.gd:1091-1103`）。

建議：
- 贏了改成同一種卡：「學大砲　★★☆（2/3）」＋三條，底下「Enter 下一關｜R 重試｜M 地圖」。
- 第 1、2 小關：卡片出來後等玩家按 Enter 才 `_start_exit()`（把 `_exit_delay` 的倒數改成等按鍵），R 打開讓人重玩。開門走進下一關的過場保留。
- 第 3 小關：Enter 回地圖。
- 之後如果有共用結算卡，換成呼叫它。

### 5. 進場卡加一句劇情

現況：進場鏡頭已經有中文紙片（`fort_battle.gd:4325-4362`），三段的字是「第 N 小關　名稱」配「人類要塞」／目標／提示（`fort_world.gd:893-910`）。這已經很接近我們要的格式。

建議：第一段的副標從「人類要塞」改成「地名＋一句劇情」。各島統一的格式是冰雪島那種：「企鵝。被抓來冰雕廣場給人拍照，不准下水。」劇情檔 `levels/ice/docs/劇情故事.md` 第 5、6 節留了空格：「這座島關的是【動物】。被抓來【做什麼】。」例如「紫霞堡　【動物】被關在城裡，替人類拉大砲。」

### 6. 右下角補 Tab

現況：右下角只有 H／R／M（`:3801-3805`），其他島是 H／Tab／R／M。Tab 本身能用，教學第一頁也寫了。

建議：在 H 後面加一行 `crow.add_child(UIStyle.key_hint("Tab", "俯看", 13))`。

### 7. 「老闆」改「指揮官」

現況：第 3 小關右上角寫「老闆（持槍）」（`:771` 取名、`:3683` 加上「持槍」，截圖 fort_3_b_end），但關名、說明都叫「指揮官」。劇情裡「大老闆」是最終章才出場的人類頭目，這裡也叫老闆會讓人以為是同一個人。

建議：`:771` 改成「指揮官」。

### 8. 進場鏡頭長度（可選）

現況：每次載入小關都播約 10.5 秒（三段 3＋3.2＋3.2 秒，再飛回 1.1 秒），從上一關走門過來也一樣。Space 可以跳過。

建議：同一次開遊戲第二次進同一關，只播一段俯瞰（約 3 秒）。用 `Engine` 的 meta 記一下就好。

### 9. 刪掉舊教學彈窗檔（可選）

現況：`levels/fort/tutorial_popup.gd` 已經沒在戰局裡用，只剩 `fort_main.gd:148` 錄示範動畫時讀它的 `FW`、`FH`、`COLS`、`FPS`。

建議：那行改成 preload 共用的 `scripts/ui/tutorial_popup.gd`（常數一樣），然後刪掉舊檔，以後才不會改錯檔。

### 10. 人類改 Q 版（長期、可選）

現況：農夫和指揮官是共用的寫實比例模型；冰雪島、丹穴山是 Kenney Mini Characters 大頭小人（`levels/ice/rescue_battle.gd:3482` 起，倒地、滑倒這些姿勢是程式擺骨頭）。你的程式用到很多模型自帶的動畫（Death、Kick、Wave、Gun_Shoot），換模型要一個一個對應，晚餐畫面也要換。

建議：工作量大，截止前不建議。真的要做先跟我們說，素材看要不要搬到共用 `assets/`，不要直接讀 `levels/ice/` 的檔案。

## 需要你回覆我們的

1. 島的地名要叫什麼？（紫霞堡、暮岩島、砲台嶼，或你自己取）城門招牌要不要留「人類要塞」？

4. 第 1、2 小關過關後改成「按 Enter 才開門」可以嗎？
5. 「老闆」改「指揮官」可以嗎？
6. 大概什麼時候能改完？地圖讀星星要配合你的時間。
