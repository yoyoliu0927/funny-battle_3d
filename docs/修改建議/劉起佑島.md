# 劉起佑島：修改建議

> 這是建議，不是規定。每一項都寫了為什麼、改哪裡、大概多少工，要不要做、怎麼做由你決定。全部只動 `levels/liuchiyu/`，不用碰共用檔案。

## 為什麼要改

試玩的人說五個大關「像五款不同的遊戲」。我們討論後覺得斷點主要不在玩法，而在戰局的外框：大關名、星星怎麼算、目標卡、結算、開場字卡，每座島各做各的。這份只談這些外框。

**不用改的**：神之手、風／雷／夜晚、開打後即時施放、三小關連成一趟走完、油畫美術方向，全部保留。世界地圖那邊（南北分區、全部用★顯示、破關拿一根紅色羽毛（照劇本的顏色）、破關過場）由我們做。

## 逐項說明

### 1. 大關名改地名

現況：`chapter.gd` 的 `TITLE := "劉起佑版"`，地圖島牌上就顯示這個。`DESC` 和三個小關的 `desc` 還是範本的字（「飼料和香蕉皮」「鞭炮」「睡覺的守衛」），跟現在的風車、枯樹林、火山對不上。

建議：`TITLE` 改地名，例如「秋楓島」。小關名可以短一點，跟別的島同一種寫法（冰雪島「雪人與冰洞」、要塞「學大砲」），例如「風車盆地」「枯樹林」「火山高原」。`desc` 順手改成現在的玩法。另外 `ORDER` 是 10，跟冰雪島一樣；地圖順序我們那邊會排，之後可能請你改這個數字。

### 2. 三顆星

現況：
- 地圖讀星星的方式：`scripts/level_select.gd:1541` 的 `_star_table()` 載入 `chapter.gd` 裡 `STARS_SCRIPT` 指的腳本，讀它的 `static var best_stars`（`{小關場景路徑: {條件 id: true}}`），每小關最多算 3 顆。讀不到就只用旗子算過關數，你的島現在就是這樣。
- 過關本身地圖已經知道（共用的 `battle_base.gd` 會寫存檔），這部分不用動。
- 你現在的星星是「每小關一顆、藏在場上」（風車頂、礁石、湖中小島），記在 `Engine` 的 meta 裡（`island_world.gd:2144-2155`），只活在這一趟，進第 1 小關時 `forget_zones()` 還會清掉（`stage_1/battle.gd:105`）。地圖讀不到。

建議：每小關三條，場上那顆星當其中一條，你的設計不用拆。依照實際玩法提的：

| 小關 | ★1 | ★2 | ★3（擇一） |
|---|---|---|---|
| 1 風車盆地 | 打倒兩個農夫 | 拿到風車頂上的星星 | 家豪沒被滾石、葉片砸到（`stage_1/battle.gd:227`、`:254`）／用沙子讓農夫看不見一次 |
| 2 枯樹林 | 打倒農夫和守門員 | 拿到礁石上的星星 | 讓農夫在水灘裡被電倒（`stage_2/battle.gd:251`）／家豪沒被電到、沒被樹壓到（`:253`、`:313`、`:421`） |
| 3 火山高原 | 打倒豪王 | 拿到湖中小島的星星 | 在湖裡用雷電倒豪王（`stage_3/battle.gd:540`）／家豪沒被岩漿燙到（`:767`） |

★1 就是現在的過關條件，不用新寫判斷。★3 都是「用到這關的副機制」或「神蹟不誤傷家豪」，第一次過關大概拿 1～2 顆，回頭再玩才拿滿。紀錄會累積，不同條件可以分幾次拿（跟冰雪島一樣）。

做法照森林（`levels/forest/forest_battle.gd:39-42`、`:851-902`、`:973-978`）：
1. `island_battle.gd` 加 `static var best_stars := {}`、`var _done := {}`、`_objectives()`（各小關覆寫，回傳 `[{id, text}]`）、`_mark_goal(id)`。
2. 達成時叫 `_mark_goal()`；過關時把 `_done` 寫進 `best_stars`，key 用 `"res://levels/liuchiyu/stage_%d/stage.tscn" % _stage_no()`（跟地圖用的一樣）。
3. `chapter.gd` 加 `const STARS_SCRIPT := "res://levels/liuchiyu/island_battle.gd"`。丹穴山就是這樣指到父類別的腳本，子類別共用同一張表。

要注意：
- 你的星星常常是**過關之後**才撿到（`island_battle.gd:198`、`stage_3/battle.gd:571`），所以不能只在 `_end("win")` 寫一次；`_collect_star()` 時如果已經過關，要直接寫進表裡。
- 星星要回到地圖才會存進存檔（地圖的 `_sync_stars()`），每座島都一樣。
- 場上那顆東西繼續叫「星星」會跟三顆目標星混在一起。可以換個名字（例如「楓葉」），或至少目標卡上寫清楚是哪一顆。

### 3. 目標卡

現況：左上角一行金字☆☆☆（`island_battle.gd:117-124`、`:153-154`），是整個大關的計數。森林、冰雪島左上角是一張米色筆記紙，三行「☆ 條件」，做到變金色。

建議：把 `_star_label` 換成森林的 `_build_goals()`／`_refresh_goals()`（`forest_battle.gd:904-954`，幾乎能整段搬），外框用 `UIStyle.paper()`。你的大關刻意少放字（`_hide_texts()` 的註解），可以折衷：準備階段展開三行，開打後縮成只剩三顆星。

### 4. Chapter N 改中文＋進場卡

現況：三個小關上空各浮一行 3D 字「Chapter 1／2／3」（`island_world.gd:540`、`:588` 起），環島預覽和打鬥時都看得到（截圖 liuchiyu_1_a_prepare 正中間、liuchiyu_3_a_prepare 左上）。字型指定 Palatino 這類英文字型（`:597-600`），直接換中文可能顯示不出來。

建議：
- `SIGN_NAMES` 改成中文小關名，`tm.font` 改用共用的粉圓體 `load(UIStyle.FONT_PATH)`（共用的可以讀）。
- 進場卡：各島統一是「地名＋一句話說家豪為什麼來、要救誰」。冰雪島是「企鵝。被抓來冰雕廣場給人拍照，不准下水。」劇情檔 `levels/ice/docs/劇情故事.md` 第 5、6 節留了空格：「這座島關的是【動物】。被抓來【做什麼】。」
- 位置：第 1 小關環島預覽時，畫面上方中間放一張紙片，寫「秋楓島　風車盆地」＋那一句；第 2、3 小關一進場顯示 3 秒。紙片做法可以看要塞的 `_build_intro_caption()`（`levels/fort/fort_battle.gd:4325-4362`）。

### 5. 過關結算

現況：第 1、2 小關過關後不跳結算，家豪自己走去下一關（`island_battle.gd:1797-1800`），這個流程很好，保留。第 3 小關才出現共用的結算框，寫整個大關的★（`stage_3/battle.gd:308-310`）。冰雪島、丹穴山的過關卡是「★★☆（2/3）」＋三條☑／☐＋新拿到的標「新！」＋沒拿到的一行提示＋「Enter 下一關」（`levels/ice/rescue_battle.gd:1091-1103`）。

建議：
- 第 1、2 小關：不要擋流程。過關那一刻把目標卡放大到畫面上方停 3 秒，顯示這關★★☆和三條，然後縮回去。R 隨時都能重試，不用另外做。
- 第 3 小關：結算改成列出三個小關各拿幾顆（讀 `best_stars`），底下「R 重試｜M 回地圖」。之後如果有共用結算卡，換成呼叫它。

### 6. 第一次進來自動開操作說明

現況：按 H 的圖解卡已經有，還多了「夜晚」一頁（`island_battle.gd:1425-1434`）。只是 `_level_setup()` 設了 `show_tutorial = false`（`:1159`），不會自己打開。

建議：保留那行（不然會在環島預覽中途跳出來），改在 `_end_intro()` 最後叫一次 `_auto_help()`（共用函式，同一次開遊戲每個大關只開一次）。從地圖直接進第 2、3 小關時也叫一次；自動測試時不要叫（`_automated_run()`）。示範動畫可以用 `tools/record_tutorial.gd -- --chapter=liuchiyu --cam_h=18` 錄，按住型的風可能要自己調。

### 7. 進場俯瞰

現況：第 1 小關每次載入播約 12 秒環島預覽（`INTRO_SHOTS`，`:1290-1297`），Space 可跳過。第 2、3 小關從地圖直接進去時沒有，一進來就在家豪背後。Tab 俯看已經有。

建議：第 2、3 小關「不是從上一關走過來」時（`island_world.gd:835` 有 `liuchiyu_cam` 就是走過來的），播一段 2～3 秒俯瞰這一區，再落到家豪背後。可以沿用 `INTRO_SHOTS` 的寫法，只放一段。

### 8. 家豪看不清楚

現況：liuchiyu_1_b_end 裡家豪站在畫面中間偏上，幾乎找不到。原因有三個：
- 油畫濾鏡把遠處的小東西抹成色塊（`oil_world.gd:195` `FILTER_SPREAD := 1.3`、`oil_filter.gdshader:8` `radius = 2`）。
- 家豪的綠框粗細用公尺算，只有 0.022、還是虛線（`island_battle.gd:554-555`）；敵人是 0.07 實線。離鏡頭一遠框就細到看不見。
- 黑色帽 T 踩在深紅褐色落葉上，本來對比就低。

建議（由小到大）：家豪的框改實線、加粗到跟敵人差不多，或依鏡頭距離調 `grow_amount`，讓螢幕上的粗細固定；`FILTER_SPREAD` 降到 1.0、`radius` 試 1；家豪腳下加一圈亮色圈（冰雪島家豪腳下有一圈青色）。

### 9. 人類改 Q 版（長期、可選）

現況：農夫、守門員、豪王用共用的寫實比例模型；冰雪島、丹穴山是 Kenney Mini Characters 大頭小人（`levels/ice/rescue_battle.gd:3482` 起，倒地、滑倒這些姿勢是程式擺骨頭）。

建議：工作量大，截止前不建議。真的要做先跟我們說，素材看要不要搬到共用 `assets/`，不要直接讀 `levels/ice/` 的檔案。
