# 開發守則：四個人各做一個大關，最後合併

## 一句話

**共用的 template 大家都不動，每個人只在自己的 `levels/<名字>/` 資料夾裡做事。**
這樣四個人的修改永遠不會碰到同一個檔案，合併的時候就不會衝突。

## 專案分成兩塊

| 共用 template（不要改） | 內容 |
|---|---|
| `scripts/battle/battle_base.gd` | 戰局引擎：準備／開打／結束、Enter 開始、R 重試、M 回地圖、家豪的 AI、一般敵人（農夫型）的 AI、血條、教學、勝敗畫面 |
| `scripts/items/` | 共用道具庫：飼料、香蕉皮、巨石，以及道具的基底 `item.gd` |
| `scripts/ui/` | 道具格（技能欄）、對話框、敵人頭像、教學箭頭 |
| `scripts/world/arena_world.gd` | 通用場地：地形、外圍森林、草、擺設、圍欄、牆、水池 |
| `scripts/player.gd`、`crosshair.gd` | WASD 飄移、空白鍵上升、Shift 下降、滑鼠視角、準心 |
| `scripts/characters.gd`、`assets/characters/`、`assets/ui/` | 主角家豪的模型和頭像、農夫模型 |
| `scripts/intro.gd`、`level_select.gd`、`loading.gd` | 開場動畫、選關地圖、載入畫面 |
| `scripts/registry.gd`、`progress.gd` | 自動找出所有大關、存檔 |
| `scenes/stage_base.tscn` | 每個小關共用的場景（燈光、天空、霧、玩家、HUD） |
| `shaders/`、`assets/`、`project.godot` | 卡通著色、共用素材、專案設定 |
| `examples/farm/` | 範例關「農場大門」：完整示範怎麼做機關、Boss、自訂敵人 |
| `tools/` | 自動測試、冒煙測試、建立大關的腳本 |

| 你自己的（隨便改） | 內容 |
|---|---|
| `levels/<名字>/chapter.gd` | 大關名稱、地圖上的城市、作者、小關清單 |
| `levels/<名字>/stage_1/`、`stage_2/`、`stage_3/`… | 每個小關的場景、場地、戰局 |
| `levels/<名字>/items/` | 你自己做的道具 |
| `levels/<名字>/assets/` | 你自己的模型、圖片、音效（附 `CREDITS.txt`） |

## 第一次開始

1. 把專案抓下來，切到自己的分支（分支名稱一定要是 `level/<名字>`，名字用英文小寫）：
   ```bash
   git clone https://github.com/yoyoliu0927/funny-battle_3d.git
   ```
   ```bash
   cd funny-battle_3d
   ```
   ```bash
   git switch -c level/tainan
   ```
2. 建立自己的大關（會從 `levels/_template` 複製一份並改好路徑）：
   ```bash
   bash tools/new_chapter.sh tainan
   ```
3. 用 Godot 4.7 打開專案，從選關地圖進你的大關試玩。開發版裡沒解鎖的小關也進得去。
4. 打開 `levels/tainan/chapter.gd`，改 `TITLE`、`CITY`、`AUTHOR`、小關名稱。

## 一個小關由三個檔案組成

```
levels/tainan/stage_1/
  stage.tscn   繼承共用的 stage_base.tscn，只換 World 和 Battle 的腳本（通常不用動）
  world.gd     場地長什麼樣子
  battle.gd    玩法：有哪些道具、哪些敵人、什麼機關、怎樣算贏
```

### world.gd：場地

```gdscript
extends "res://scripts/world/arena_world.gd"

func _configure() -> void:
	play_min = Vector2(-12, -12)          # 遊玩範圍
	play_max = Vector2(12, 14)
	hero_start = Vector3(0, 0, 11)        # 家豪出生點
	camera_start = Vector3(5, 7, 18)      # 玩家（神）一開始在哪
	fences = [[Vector2(-7, 6), Vector2(7, 6)]]       # 矮圍欄：家豪飛得過、敵人要繞
	walls = [[Vector2(-12, -2), Vector2(-4, -2)]]    # 牆：誰都過不去
	ponds = [{"center": Vector2(-5, -1), "r": 3.6}]  # 水池：敵人走進去會淹死
	props = [{"model": "res://levels/tainan/assets/temple.glb", "pos": Vector3(6, 0, -6), "scale": 1.0, "block": 2.5}]
	ground_a = Color(0.6, 0.72, 0.3)      # 地面顏色（每關可以有自己的風格）
```

- 想要山坡等特殊地形：覆寫 `_extra_height(x, z)`（見 `levels/_template/stage_3/world.gd`）。
- 想自己蓋東西：覆寫 `_build_extra()`。
- 天空、霧、燈光的顏色：在 `stage.tscn` 裡改 WorldEnvironment 和 Sun（這是你自己的檔案，不會影響別人）。

### battle.gd：玩法

```gdscript
extends "res://scripts/battle/battle_base.gd"

const FeedItem := preload("res://scripts/items/feed_item.gd")
const BananaItem := preload("res://scripts/items/banana_item.gd")
const RockItem := preload("res://scripts/items/rock_item.gd")

func _make_items() -> Array:
	return [
		FeedItem.new().uses(2, -1),        # 準備階段 2 次、開打後不限次數（-1 = ∞）
		BananaItem.new().uses_shared(3),   # 準備＋開打共用 3 次
		RockItem.new().uses(0, 2),         # 準備階段不能用、開打後 2 次
	]

func _enemy_specs() -> Array:
	return [
		{"name": "攤販1", "route": [Vector3(-4, 0, 1), Vector3(4, 0, 1)], "loop": false, "pause": 1.5},
		{"name": "攤販2", "route": [Vector3(3, 0, -6)], "speed": 2.2, "kick_damage": 3.0},
	]
```

**道具次數**：分「準備階段」和「開打後」兩段算，按 Enter 開打時道具格的數字會播一段切換動畫；
`uses_shared(n)` 是兩段共用一個數字（開打時不切換）；`-1` 顯示 ∞。

**敵人可以設定的東西**（都可以省略）：`name`、`route`（第一個點是出生點）、`loop`、`pause`、`model`（`"farmer"`、`"merchant"` 或自己的 .glb 路徑）、
`hp`、`speed`、`reach`、`kick_damage`、`heavy_damage`、`vision_range`、`vision_deg`、`immune_peck`、`immune_rock`、`can_slip`、
`has_cone`、`hears_noise`、`target_last`、`is_boss`、`portrait`（頭像圖片）、`hud_name`、`bar_y`、`kind`。

**可以覆寫的函式**（全部列在 `battle_base.gd` 最上面「關卡可以覆寫」那一區）：

| 函式 | 什麼時候用 |
|---|---|
| `_make_items()` | 這關有哪些道具、各幾次 |
| `_enemy_specs()` | 這關有哪些敵人 |
| `_level_setup()` | 建好角色之後做一次：準備機關 |
| `_level_reset()` | 按 R 重試時：把機關恢復原狀 |
| `_level_start()` | 按 Enter 開打時 |
| `_level_step(dt)` | 開打後每 1/60 秒：機關的動作 |
| `_tick_enemy(f, dt)` | 自訂敵人（`kind`）的 AI，其他交給 `super(f, dt)` |
| `_on_rock_rolling(rock, pos, speed)` | 巨石撞到你的機關 |
| `_check_end()` | 改輸贏條件（例如「撐過 30 秒」「把家豪送到某個地方」） |
| `_tutorial_texts()`、`_prepare_hint()`、`_win_line()`、`_lose_line()`、`_defeat_title()`、`_defeat_tip()` | 各種文字 |

**常用的小工具**：`toast("砰！", 1.0)` 畫面跳字、`say("台詞")` 對話框、`log_event()` 戰鬥紀錄、
`knock_out(敵人)` 直接打倒、`hit_bird()` 家豪挨打、`start_fly()` 家豪飛走、`noise_at(位置)` 吸引敵人、
`spawn_timed(節點, 秒數)` 會自己消失的特效、`anim(角色, "動畫名")`。

### 自己做道具

在 `levels/<名字>/items/` 新增一個檔案，照 `levels/_template/items/firecracker_item.gd`（鞭炮）改：
`_init()` 設定名字、說明、顏色、冷卻；`cast()` 放東西；`step()` 每 1/60 秒更新；`placement_error()` 決定哪裡不能放。
有圖示的話 `icon = load("res://levels/<名字>/assets/xxx.png")`，沒有的話道具格會畫一個彩色圓圈加上名字的第一個字。

## 每天的 Git 流程

```bash
git pull origin main
```
```bash
git add levels/tainan
```
```bash
git commit -m "台南第二小關：加鞭炮"
```
```bash
git push -u origin level/tainan
```

- **只 `git add` 自己的資料夾**，不要用 `git add .`。
- 每天開工前 `git pull origin main`，拿到 template 的更新。
- `git status` 看到自己資料夾以外的檔案有變動（常見：Godot 編輯器自動改了 `project.godot` 或共用的 .tscn），用 `git restore <檔案>` 還原。
- 做好一個段落就到 GitHub 開 Pull Request 到 `main`。GitHub 會自動檢查你只改了 `levels/<名字>/`，改到別的地方會擋下來。

## 需要改共用的 template 怎麼辦

例如：想讓家豪多一個動作、道具格要多一種顯示、引擎有 bug。

1. 不要自己在自己的分支改共用檔案（PR 會被擋）。
2. 跟 template 負責人說要改什麼、為什麼，最好附上你的小關當作例子。
3. 負責人開 `core/xxx` 分支改，改完跑過所有大關的冒煙測試再合進 `main`。
4. 大家 `git pull origin main` 拿到新版。

能用覆寫做到的就先用覆寫，不要動共用檔案。

## 用 AI 修改時

專案根目錄有 `AGENTS.md`（`CLAUDE.md` 會引用它），Claude Code、Codex、Cursor 等工具會自動讀到裡面的規則。給 AI 下指令時，建議開頭這樣講：

> 我負責 `levels/tainan/` 這個大關，只能改這個資料夾。請先讀 AGENTS.md 和 docs/開發守則.md。
> 我想在第二小關加一個……

AI 改完之後，自己再確認一次：
1. `git status` 只有 `levels/tainan/` 有變動。
2. 冒煙測試通過（下面那行）。
3. 自己進遊戲玩一次。

## 合併前的檢查（每次開 PR 前）

```bash
Godot --headless --path . -s res://tools/smoke_test.gd -- --chapter=tainan
```

它會打開你每一個小關、自動開打一陣子、按 R 重置，確認沒壞掉、家豪和敵人都站在走得到的地方、至少有 3 個小關。
看到 `SMOKE: ALL PASS` 才開 PR。拿掉 `--headless` 並加上 `--shots=<資料夾>` 會每關截一張圖。

（`Godot` 換成你電腦上的執行檔，Mac 通常是 `/Applications/Godot.app/Contents/MacOS/Godot`。）

## 最後合併

1. 四個人的 PR 都合進 `main`（因為各自只改自己的資料夾，順序不重要）。
2. 負責人在 `main` 跑一次全部的冒煙測試（不加 `--chapter`），再從開場一路玩到底。
3. 決定地圖上的順序：改各大關 `chapter.gd` 的 `CITY` 和 `ORDER`（地圖上的城市有高雄、台南、台中、新竹、台北）。
4. 正式匯出時，`_template` 這種底線開頭的資料夾會自動隱藏。

## 常見問題

- **選關地圖看不到我的大關**：檢查 `levels/<名字>/chapter.gd` 有沒有存在、`STAGES` 的 `scene` 路徑對不對。
- **小關一進去就壞掉**：多半是 `world.gd` 或 `battle.gd` 有錯字，Godot 下方的「除錯工具」或命令列會寫在哪一行。
- **Godot 說 UID 重複**：你可能是手動複製 `_template`，請刪掉自己資料夾裡所有 `.uid` 檔讓 Godot 重新產生，或改用 `tools/new_chapter.sh`。
- **敵人卡在牆裡、家豪走不過去**：檢查 `props` 的 `block` 半徑、`fences`、`walls`；冒煙測試會檢查出生點是不是走得到。
