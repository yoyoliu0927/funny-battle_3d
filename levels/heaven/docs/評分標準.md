# 仙境丹穴山　評分標準

給試玩的評審用。三位評審各自玩完三個小關，照下面五個面向各打 1～10 分（可以用 0.5），再照比重算總分。
目標：三位的總分都超過 8。

## 背景（評審需要知道的）

- 這是整個遊戲的最終章。玩家是天上的神，只能在開打前往場地上丟道具；主角家豪（黑帽 T 的公雞，平常會「虛空打碟」）自己沿黃線走到終點。
- 玩法沿用前一章冰雪島：工人沿紅線跑來抓家豪，踩到香蕉皮會一路滑出去，滑的人會撞到別人，滑進洞就出局。
- 這一章新的東西：畫門（滑進一幅畫，從成對的另一幅出來）、陸吾（吹走第一個走進金光的）、巨石（只能放在雲階上）、唱盤上的飼料。
- 美術方向：故事取材山海經，畫面想要「一幅展開的山海畫卷」的感覺。三關依序是：雪梅融成青綠山水 → 金黃燈火的畫中小鎮 → 星空下的山海轉盤。一道金色的鳳羽靈光一路替家豪引路；結局家豪站上唱盤打碟，轉盤轉起來，他是鳳凰的後代。
- 美術的比較基準是同一個遊戲的冰雪島（學生小組作品裡做得最完整的一章），不是商業大作；但「像不像一張完整的畫面」還是要嚴格看。

## 五個面向

### A. 玩法與機制（25%）
- 規則是不是一致、說得清楚：同樣的放法每次結果一樣，結果能用規則解釋。
- 新機制（畫門、陸吾、巨石、唱盤）是不是真的要用到，不是擺好看的。
- 有沒有不只一種解法；三顆星是不是逼你用不同的想法再玩一次。
- 機制之間有沒有好玩的互相作用（例如把人送進畫門再掉進洞、讓陸吾吹走別人）。

| 分數 | 大概是這樣 |
|---|---|
| 9–10 | 每一關都有「原來可以這樣」的瞬間，新機制互相咬合，會想再玩拿星星 |
| 7–8 | 規則清楚、機制有用到，解法有兩種以上，偶爾有一處鬆散或多餘 |
| 5–6 | 能玩，但解法單一，或新機制可有可無 |
| ≤4 | 規則不一致、結果說不通，或亂放也能過 |

### B. 關卡難度與曲線（20%）
- 三關是不是一關比一關多一點東西（第 1 關教畫門、第 2 關教陸吾、第 3 關合起來）。
- 容錯合不合理：保底解法不用對到幾十公分；進階的星星才需要對時機或位置。
- 「什麼都不放」和「放錯」的失敗有沒有讓你知道下一次該改什麼。
- 最後一關像不像壓軸（人最多、要想最久），但不會難到只能試誤。

| 分數 | 大概是這樣 |
|---|---|
| 9–10 | 曲線順，保底幾次就過、三星要動腦，失敗都學得到東西 |
| 7–8 | 曲線大致順，有一關偏簡單或有一處容錯太緊 |
| 5–6 | 有一關明顯太簡單／太難，或要靠試誤 |
| ≤4 | 難度亂跳，或只有一個幾十公分的位置能過 |

### C. 美術與山海畫境的氛圍（25%）
- 三關的主題一眼分得出來，色彩和光線各有性格，合起來又像同一卷畫。
- 構圖有層次：近景、能玩的場地、遠景；能玩的地方不是孤零零一塊。
- 模型的風格一致，不像基本形狀硬拼；跟人物放在一起不突兀。
- 山海經／畫卷的元素有沒有出現在畫面上而且看得懂（立軸畫門、紅梅、樓閣、山海轉盤和異獸紋章、鳳羽靈光）。
- 跟冰雪島比，完成度有沒有差不多或更好。

| 分數 | 大概是這樣 |
|---|---|
| 9–10 | 每一關截下來都像一張完整的畫，主題強烈、細節經得起看 |
| 7–8 | 氛圍到位，有一兩處粗糙（某個模型、某塊空地、某個顏色） |
| 5–6 | 看得出想做什麼，但畫面空、雜或風格不統一 |
| ≤4 | 像測試場景 |

### D. 看得懂與回饋（15%）
- 準備階段一眼看得出：誰會往哪跑、哪裡會滑、哪裡是洞、終點在哪、道具剩幾個。
- 畫門的成對關係、陸吾的金光範圍、巨石能放哪裡，畫面上有沒有表示。
- 畫面上的字（清單、便利貼、名牌、狀聲字、失敗提示）是不是短、清楚、不互相蓋住。
- 裝飾（樹、攤子、轉盤、靈光）有沒有擋到要看的東西。

| 分數 | 大概是這樣 |
|---|---|
| 9–10 | 不看說明也知道要做什麼，出事的原因一看就懂 |
| 7–8 | 大致清楚，有一兩個東西要多看幾眼或被擋住 |
| 5–6 | 要靠試才知道規則 |
| ≤4 | 看不出發生什麼事 |

### E. 故事與收尾（15%）
- 「畫卷」和「鳳凰」有沒有從第一關貫穿到結局（不是只有最後才出現）。
- 結局的演出：家豪打碟 → 轉盤 → 鳳凰，有沒有讓人覺得是整個遊戲的收尾，有沒有保留這個遊戲的搞笑感。
- 過關、失敗的小演出（特寫、狀聲字、台詞）有沒有趣味。

| 分數 | 大概是這樣 |
|---|---|
| 9–10 | 收尾有記憶點，前面埋的東西最後都收回來 |
| 7–8 | 有完整的收尾，節奏或某個鏡頭還可以更好 |
| 5–6 | 有結局卡片，但沒有演出感 |
| ≤4 | 過關就沒了 |

## 總分

總分 = A×0.25 + B×0.20 + C×0.25 + D×0.15 + E×0.15

## 評審要交的東西

1. 五個面向各自的分數和一兩句理由（要講到具體的關卡、位置或截圖檔名）。
2. 總分（照上面的比重算，四捨五入到小數一位）。
3. 最多五條「改了分數會變高」的具體建議，照影響大小排。
4. 玩的時候試過哪些放法、結果如何（簡短列出，方便對照）。
