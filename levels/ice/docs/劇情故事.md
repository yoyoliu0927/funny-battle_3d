# 劇情故事與對話腳本

> 這是第一版。開頭和結局以 `開頭與結局劇情.md` 為準；中間各大關、各小關的劇情以 `全遊戲劇情.md` 為準（2026-11-26）。

整個遊戲從開頭到結局的故事和對話。第一章（冰雪島）和最終章（仙境丹穴山）是我負責的；中間兩章是組員的，這裡先寫好可以直接套用的對話，【】裡的字等組員決定後填。

仙境三關的玩法規格在同一層的 `仙境關卡規格.md`。

## 1. 一句話

一隻在屋頂上虛空打碟、被當成怪胎的雞，被神手滑選中去救動物，最後才發現牠搓的不是空氣，是失傳的祭天舞。

## 2. 設定

### 2.1 底牌

《山海經·南山經》：「丹穴之山……有鳥焉，其狀如雞，五采而文，名曰鳳皇……是鳥也，飲食自然，自歌自舞，見則天下安寧。」

- 「其狀如雞」：家豪是流落凡間的鳳凰後裔。
- 「自歌自舞」：牠的虛空打碟就是失傳的「百鳥朝鳳祭天舞」。
- 「五采而文」：每救完一座島，牠連帽羽衣底下多一根有顏色的羽毛。

### 2.2 角色

| 角色 | 是誰 | 說話的樣子 |
|---|---|---|
| 家豪 | 公雞。全黑連帽羽衣、黑口罩，每天在雞舍屋頂上虛空打碟 | 話很少，開頭常是「……」，不解釋 |
| 神 | **就是玩家**。值班的小神，不能下凡動手，只能往凡間丟東西（香蕉皮、飼料） | 懶、嘴硬、愛吃供品，出事就說「天意」 |
| 雞舍的雞 | 把家豪當怪胎的同類 | 碎嘴 |
| 阿土、阿水 | 工人，每一章都出現，每一章都滑倒 | 只想下班 |
| 守衛 | 站著不動、不怕香蕉皮 | 幾乎不說話 |
| 大老闆 | 人類的頭，最終章才露面，穿金釘鞋，後面跟著抬金籠子的阿金 | 把所有動物都叫「貨」 |
| 陸吾 | 丹穴山看門的神獸，虎身九尾的大貓 | 照規定辦事，句子很短 |

### 2.3 為什麼玩家只能放道具

神不能下凡動手，這是天上的規定。牠能做的只有往下丟東西，而牠手邊只有供桌上的東西：香蕉吃完剩下皮，還有一包拜拜用的飼料。

所以整個遊戲的玩法就是故事本身：**神在旁邊丟東西，家豪只管往前走。**

### 2.4 貫穿全遊戲的三條伏筆

每一章破關都重複同樣三件事，到結局一次收回來：

1. **打碟沒有聲音**：家豪每次破關都搓兩下慶祝，玩家聽不到任何聲音。結局是整個遊戲第一次有聲音。
2. **鳥會來**：牠一搓，附近的鳥就靠過來跟著晃。一章比一章多。神以為是巧合。
3. **羽毛**：每過一章，帽子底下多一根有顏色的羽毛，家豪自己沒發現。

### 2.5 寫對話的規則

- 每一段最多八句，每句不超過十五個字。
- 標「可刪」的句子拿掉不影響理解，畫面放不下就先刪。
- 家豪不說大道理，神不說實話。

## 3. 序章　凡間雞舍

### 3.1 屋頂上的怪胎

（黃昏。雞舍屋頂上，家豪戴著帽子和口罩，兩隻翅膀在空氣裡搓。完全沒有聲音。）

| 誰 | 台詞 |
|---|---|
| 母雞 | 他又上去了。 |
| 小雞 | 媽，他在搓什麼？ |
| 母雞 | 不要看。會變成那樣。 |
| 公雞 | 喂，家豪！雞是用叫的，不是用搓的！ |
| 家豪 | ……是你們聽不到。 |
| 公雞 | 戴口罩是怕禽流感嗎？（可刪） |

### 3.2 天選之雞

（天上。神躺著吃供桌上的香蕉，面前攤著一本名冊。）

| 誰 | 台詞 |
|---|---|
| 神 | 人間又有一堆動物被關起來。該選個幫手了。 |
| 神 | 上次選人，人把大家都關起來了。這次不選人。 |
| 神 | （手指在名冊上滑）牛……太慢。老虎……太兇。 |
| | （手一滑，香蕉皮掉下去。一道金光打在屋頂的家豪身上。） |
| 神 | ……就你了。 |
| 家豪 | ……誰。 |
| 神 | 神。你是天選之雞，去把被關的動物救出來。 |
| 家豪 | 為什麼是我。 |
| 神 | （看著自己空空的手）……天意。 |

### 3.3 神只會丟東西

（阿土拿著網子爬上屋頂要抓雞，一腳踩到剛剛掉下來的香蕉皮，整個人滑出去。）

| 誰 | 台詞 |
|---|---|
| 阿土 | 哇啊啊啊—— |
| 家豪 | ……有用。 |
| 神 | 看到沒，都在我的計算裡。 |
| 家豪 | 我只會這個。（搓兩下） |
| 神 | 夠了。你負責往前走，其他的我丟給你。 |
| 神 | 我不能下去動手，規定。我只能丟東西。 |
| 家豪 | ……你手上只有香蕉皮。 |
| 神 | 供品今天就拜這個。走了。 |

（雞舍的雞全部抬頭，看著家豪走出大門。）

| 誰 | 台詞 |
|---|---|
| 公雞 | 他去哪？ |
| 母雞 | 不要看。（可刪） |

## 9. 過場畫面清單

每個過場都是幾張圖加上面的對話，不做長動畫。照必要程度排：

| 順序 | 位置 | 對應章節 | 必要 |
|---|---|---|---|
| 1 | 遊戲開頭 | 3.1～3.3 | 必要（來不及就只留 3.2） |
| 2 | 冰雪島破關 | 4.2 | 必要 |
| 3 | 結局 | 8.1～8.3、8.7 | 必要 |
| 4 | 仙境開場和各關開場 | 7.1～7.4 | 有最好 |
| 5 | 結局其他段落 | 8.4～8.6 | 有最好 |
| 6 | 第二、三章開場和破關 | 5、6 | 看組員 |
| 7 | 冰雪島開場 | 4.1 | 可省 |

聲音是結局的關鍵：前面每一次打碟都不能有任何音效，結局才第一次放音樂。

## 10. 還沒決定、需要配合的事

- **冰雪島現有的台詞**：遊戲裡家豪現在的台詞是「……我只是去吃飯」這一類。新的家豪是打碟的怪胎，不是貪吃。要不要把冰雪島各關的過關、被抓台詞改掉，等你決定。
- **中間兩章**：【】的內容要組員填。需要他們配合的只有三件事：破關時家豪搓兩下沒聲音、鳥飛過來、多一根羽毛。
- **只剩三個大關或兩個大關時**：羽毛數量跟著減，第 6 章的「三次巧合」改成對應的次數。
- **大老闆的造型和名字**還沒定。
- **神的樣子**：玩家就是神，建議畫面上只出現一隻手和香蕉，不畫臉。
