# 選關地圖播大關開場、結尾動畫：要改的地方

各大關的開場、結尾動畫都做在 `levels/ice/story/`，什麼時候播由 `levels/ice/story/story_registry.gd` 判斷。

「進一章之前先播開場」「破完一章回地圖先播結尾」要從選關地圖（`scripts/level_select.gd`）去叫。這是四個人共用的檔案，**2026-11-27 使用者同意後已經照下面改了**。

- 冰雪島、丹穴山本來就會播（這兩章自己的關卡會轉過去），接上地圖之後也不會重播：播過就記起來，第二次問的時候回空字串。
- 駁大莖森、霧山楓燃、人類要塞從這一版開始也會自動播。
- 要拿掉的話，把下面兩段改回「原本」就好；或刪掉 `story_registry.gd`，地圖就照舊。

驗證過（乾淨的存檔、開視窗跑）：全新存檔五章的開場都會回傳；把森林全破、從 `forest/1` 回地圖會先進 `forest_ending.tscn`，第二次回地圖就直接是地圖；在霧山第 1 關按進入會先進 `liuchiyu_opening.tscn`，播完要去的關卡（`next_scene`）是霧山第 1 關。冰雪島、丹穴山的冒煙測試都 `SMOKE: ALL PASS`。

## 改了的兩個地方

一共加大約 20 行，不動原本的邏輯。`story_registry.gd` 不存在時，兩個函式都回傳空字串，地圖照舊。

### 一、進關卡之前（`start_selected()` 最後換場景那裡）

原本：

```gdscript
	Engine.set_meta("next_scene", stage.scene)
	Engine.set_meta("stage_id", stage.id)
	get_tree().change_scene_to_file("res://scenes/loading.tscn")   # 先進載入畫面
	return true
```

改成：

```gdscript
	Engine.set_meta("next_scene", stage.scene)
	Engine.set_meta("stage_id", stage.id)
	# 第一次進這一章：先播大關的開場動畫（播完它自己進這一關），不然先進載入畫面
	var opening := _story_opening(String((s.ch as Dictionary).get("id", "")))
	get_tree().change_scene_to_file(opening if opening != "" else "res://scenes/loading.tscn")
	return true

## 大關的開場、結尾動畫：levels/ice/story/story_registry.gd 管（只播一次、測試不播）。沒有那個檔案就都不播
const STORY_REGISTRY := "res://levels/ice/story/story_registry.gd"

func _story_opening(chapter_id: String) -> String:
	if chapter_id == "" or not ResourceLoader.exists(STORY_REGISTRY):
		return ""
	return String(load(STORY_REGISTRY).opening_for(chapter_id))

func _story_ending_on_return() -> String:
	if not ResourceLoader.exists(STORY_REGISTRY):
		return ""
	return String(load(STORY_REGISTRY).ending_on_return())
```

### 二、地圖一進來（`_ready()` 最前面）

原本：

```gdscript
func _ready() -> void:
	WebPerf.install(get_tree())
```

改成：

```gdscript
func _ready() -> void:
	WebPerf.install(get_tree())
	# 剛破完一章回到地圖：先播那一章的結尾動畫（播完會再回到地圖），地圖先不蓋
	var story_end := _story_ending_on_return()
	if story_end != "":
		set_process(false)
		set_process_unhandled_input(false)
		get_tree().change_scene_to_file.call_deferred(story_end)
		return
```

## 播放的規則（story_registry.gd）

- **開場**：這一章還沒看過開場，而且一關都還沒過（開場做出來之前的舊存檔就不補播）。
- **結尾**：剛剛玩的那一章（Engine 的 `stage_id`，例如 `forest/3`）已經全部過了，而且還沒看過結尾。
- **只播一次**：記在 `user://settings.cfg` 的 `[story]`，一開始播就記，按 Esc 跳過也算看過。
- **測試不播**：無頭模式、帶測試旗標（`--autotest`、`--mapshots=`…）都不播，也不寫存檔。

冰雪島第 6 關、丹穴山第 3 關的結尾是過關卡片按 Enter 時自己播的，回到地圖時已經記成看過，不會重播。

## 不用破關就想看

直接開場景。加 `-- --story` 是不管看過沒有都播，而且不寫存檔：

```bash
Godot --path . res://levels/ice/story/forest_opening.tscn -- --story
```

其他場景：`forest_ending.tscn`、`liuchiyu_opening.tscn`、`liuchiyu_ending.tscn`、`fort_opening.tscn`、`fort_ending.tscn`、`heaven_opening.tscn`。
