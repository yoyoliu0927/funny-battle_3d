# 全遊戲劇情：每一大關、每一小關

這份把五個大關、十九個小關串成一個故事。

開頭和結局已經做進遊戲（`開頭與結局劇情.md` 第 4、5 節），這份不改它們，只寫中間的部分：
- 每一大關的上岸和破關
- 每一小關的開場、過關、被抓
- 大關之間回農莊的小段落

這份只是劇本，沒有改任何程式。舊的 `劇情故事.md` 第 4～7 節由這份取代；那一版的家豪是四十七號，羽毛和鳥的寫法也和現在的結局不同。

大關的順序，和每一大關的上岸（開場動畫）、破關（結尾動畫），都在 `大關開場與結尾動畫.md`，以那一份為準。這份留著主線、伏筆、各小關的台詞和回農莊。

## 1. 一句話

一隻雞打碟打了一輩子，從來沒有人聽得到。牠脖子上掛著朋友留下的腳牌，出門去看「更好的地方」長什麼樣子。

一座島一座島看下來，人類說的「更好的地方」都是籠子。最後牠在最高的山上第一次被聽見，然後回家。

## 2. 已經定下來、不改的

**開頭**（`scripts/intro.gd`）
- 家豪是六十七號。隔壁的六十六號嘉欣被抓上卡車，大家說她「去了更好的地方」。整個雞舍只有她會問家豪「今天放什麼歌？」
- 神明選家豪，是因為整座農場只有牠每天黃昏抬頭看天。神明不能替牠打，只能讓「路上剛好多出一些東西」。
- 家豪把六十六號的腳牌掛在脖子上：「我去看看那個更好的地方，到底長什麼樣子。」

**結局**（`levels/heaven/ending/ending.gd`）
- 丹穴山的石門是一張唱盤，家豪的打碟第一次有聲音。家豪問神明「你有聽到嗎？」，神明說「有」。
- 陸吾說家豪是鳳凰的後裔，家豪化成鳳凰。
- 百鳥打開鐵皮屋，嘉欣不在裡面。
- 回到屋頂，公雞問「那個更好的地方呢？」，家豪說「……沒有那種地方。所以我回來了。」最後公雞問「今天放什麼歌？」

中間要做的事只有一件：結局要回收的東西，一路上都要先種下去。

## 3. 主線和伏筆

### 3.1 一張表看完

| 大關 | 人類說的「更好的地方」 | 其實是 | 家豪這一章往前一步 | 腳牌 | 神明 |
|---|---|---|---|---|---|
| 冰羽踏雪 | 企鵝樂園 | 關在籠子裡給人拍照 | 第一次有人跟牠說謝謝 | 「這個不是我的。」 | 很有把握 |
| 駁大莖森 | 外婆家 | 裝成外婆的狼 | 救了一個人類小孩 | 「……朋友的。」 | 代班的神 |
| 霧山楓燃 | 秋收祭 | 主菜是家豪 | 知道神明也沒人理 | — | 這座島以前拜祂 |
| 人類要塞 | 牆裡面 | 出貨板上一格一格的號碼 | 離嘉欣最近的一次 | （沒說話） | 「門關上之後我也看不到」 |
| 丹穴山海 | 鳳凰住的地方 | （結局） | 第一次說出她的名字 | 「她叫嘉欣。」 | 「名冊上沒有你」 |

### 3.2 主線：更好的地方

每一座島都是人類口中的某一種「更好的地方」。家豪去看了，每一座都不是。

每破一章，家豪在冒險手帳「旅程」頁那一章的卡片上寫一句（現有的 `scripts/hub/hub_journal.gd`）：

| 大關 | 手帳上的一句 |
|---|---|
| 冰羽踏雪 | 企鵝樂園。企鵝不覺得是樂園。 |
| 駁大莖森 | 外婆家。外婆不在家。 |
| 霧山楓燃 | 秋收祭。主菜是我。 |
| 人類要塞 | 牆裡面。六十六號下面寫著已出貨。 |
| 丹穴山海 | 屋頂。 |

最後一格只寫「屋頂」，是結局那句「所以我回來了」的答案：更好的地方就是原來那個屋頂。

### 3.3 三條伏筆（結局要回收）

**一、六十六號的腳牌**（回收：結局的「她會想聽的」「有找到嘉欣嗎」）

一路上有人問起脖子上的牌子，家豪每一章的回答都往前一步：

| 在哪 | 誰問 | 家豪 |
|---|---|---|
| 冰羽踏雪 破關 | 企鵝老大 | ……這個不是我的。 |
| 駁大莖森 破關 | 小紅帽 | ……朋友的。 |
| 人類要塞 破關 | （出貨板，沒人問） | （沒說話，摸一下牌子） |
| 丹穴山海 第 3 關 | 大老闆 | ……她叫嘉欣。 |
| 結局（已做） | | ……她會想聽的。 |

**二、沒有聲音的打碟**（回收：結局第一次有聲音）

每個大關最後一關過關、天黑的時候，家豪照老習慣打兩下碟，玩家聽不到。每一章都有誰跟著晃：企鵝、小紅帽、跪著的農夫、投降的砲手。但沒有一個說聽到了。

打完家豪會說一句。這四句是 `開頭與結局劇情.md` 第 6 節定的，順序定了以後直接綁在各章：

| 大關 | 家豪 |
|---|---|
| 冰羽踏雪 | ……今天放什麼歌。也沒人問。 |
| 駁大莖森 | ……嘉欣會說這首太吵。 |
| 霧山楓燃 | 今天放的是……算了。 |
| 人類要塞 | （打到一半停下來，摸一下牌子，什麼都沒說。） |

可以省的畫面：旁邊樹上停的鳥一章比一章多（一隻、幾隻、一排、滿樹），接丹穴山上岸那句「鳥都往這裡飛」。

**三、羽毛**（回收：結局帽子被掀開、長出五色尾羽）

每破一章，帽子底下多一根羽毛。神明看到了，家豪不承認。兩個都沒想到鳳凰，因為結局神明說「我也是現在才知道」，所以神明不能猜到：

| 大關 | 神明 | 家豪 |
|---|---|---|
| 冰羽踏雪（青） | 你帽子裡是不是有東西？ | 沒有。 |
| 駁大莖森（黃） | 又一根。 | ……換毛啦。 |
| 霧山楓燃（紅） | 顏色還不一樣。 | ……換毛啦。 |
| 人類要塞（紫） | 四根了。你換毛換很兇。 | ……壓力大。 |

**還有兩個小伏筆**
- **摔下來的次數**：要塞第 1 關家豪被大砲射上炮塔，說「這不算飛」，神明說「算摔。我有在記。」結局家豪說自己從屋頂摔過三次，神明糾正「四次」，就有了來源。
- **帽子拉低**：結局神明說「你每次怕的時候，帽子都會拉更低。」所以中間家豪怕的時候，舞台指示都寫「把帽子拉低」（要塞上岸、丹穴山第 3 關），不用台詞。

### 3.4 神明線：兩個沒人理的

結局最重的一句是神明的「有」：世界上第一個聽到家豪的，是神明。要讓這一句有分量，中間要讓玩家慢慢看出來，神明自己也是一個沒人拜的神。家豪每天黃昏抬頭，剛好是唯一一個在看祂的。

| 在哪 | 神明 |
|---|---|
| 開頭（已做） | 只有你每天黃昏會抬頭看天上。 |
| 冰羽踏雪 | 很有把握：「在冰上，人會滑，你不會。」 |
| 駁大莖森 | 「這片森林的神請假。今天我代班。」 |
| 霧山楓燃 | 「這座島以前拜我。現在拜豪王。」廟倒了，好久沒人來。 |
| 人類要塞 | 「牆裡沒有廟。在這裡，我跟幽靈差不多。」 |
| 丹穴山海 第 2 關 | 陸吾：「名冊上沒有你。」神明：「習慣了。」家豪：「……我也是。」 |
| 結局（已做） | 「你有聽到嗎？」「有。」 |

這條線也順便把各大關不同的「玩家身分」寫法接起來：森林寫「駁大莖森之神」，那是代班；要塞寫「飄在空中的幽靈」，那是神明在沒有廟的地方自己說的。

### 3.5 號碼

人類把要帶走的東西都編了號：雞的腳牌、企鵝的翅環、樹上的紅漆號碼、要塞的出貨板。

結局鳥群把雞腳上的牌子全部拿掉，已經做了（屋頂那一幕「號碼牌一塊都不剩」）。這一條不用台詞，各章畫面上看得到號碼就夠。

各島木箱、卡車上蓋的章，建議統一成一個紅圈裡寫「貨」字。大老闆把所有動物都叫「貨」，家豪在冰雪島第 4 關認出這個章，丹穴山第 3 關跟他說「牠們不是貨」。

### 3.6 一路重複的笑點

- **尋雞啟事**
  - 農場發懸賞找六十七號，每一章都貼在路邊：「尋雞啟事　六十七號　白公雞　黑帽子黑口罩」。這也解釋了每座島的人為什麼一看到家豪就追。
  - 懸賞一章比一章高：冰雪島飼料一包、森林三包、霧山十包（還被豪王蓋了「已預訂」）、要塞一卡車。
  - 到丹穴山，大老闆自己上山來抓。
- **阿土、阿水**
  - 老闆的兩個工人，只在冰雪島和丹穴山出場，每次都只想下班。
  - 冰雪島破關，阿水說「我要調單位」。到丹穴山第一關，兩個人爬上山，頭髮還結著冰。阿土問「你不是說要調單位？」阿水說「……我說的不是這種調。」
- **供品升級**：神明手邊有什麼就丟什麼。每一章多出來的道具，神明都說是今天的供品。
- **口頭禪**：家豪的「……懂的都懂」只在大場面用，一章最多一次。

## 4. 旅程順序（定案）

冰羽踏雪 → 駁大莖森 → 霧山楓燃 → 人類要塞 → 丹穴山海。上一章破完，下一座島才開。

照這個順序，情緒一路往下沉，在要塞的出貨板最低，上山再翻上來。理由和整個遊戲的流程在 `大關開場與結尾動畫.md` 第 1、2 節。

**每座島都是一天**，加上開場和結局一共一個禮拜（嘉欣是「上禮拜」被抓走的）。現有的時段剛好都是從白天打到天黑：
- 冰雪島：早晨到極光夜
- 森林：早晨到夜
- 霧山：午後到夜
- 要塞：午後到日落

家豪在雞舍每天黃昏打碟，所以每座島最後一關過關、天黑的時候，牠照老習慣打碟。破關那一段就放在這裡。

丹穴山的時段（月夜、午後、星空）不照順序走，上岸時神明說一句「山上的時間不照順序走」就好。

## 5. 每一大關、每一小關

格式：
- **上岸、破關**：寫在 `大關開場與結尾動畫.md`（畫面、台詞、聲音），這裡只留指向那一份的一行。
- **每一小關**：一句話的故事、開場（最多 3～4 句）、過關一句、被抓一句。標「現有」的是遊戲裡已經有的台詞，不用改。
- **回農莊**：居民搬來時說的話（`scripts/hub/hub_growth.gd` 已經做了，照用）。

舞台指示寫在括號裡，「誰」那一格空著。

### 5.1 冰羽踏雪：企鵝樂園

一整天的行程：
1. 漁村・早晨
2. 冰雕廣場・正午
3. 冰晶溪谷・細雪
4. 燈塔・傍晚
5. 鐘樓・黃昏
6. 燈籠夜市・極光夜

企鵝今天一路被送：早上從碼頭送到廣場拍照，傍晚裝箱上船，晚上在夜市壓軸表演。家豪一路追。

**這一章家豪往前一步**：第一次有人跟牠說謝謝。

**上岸**：開場動畫，見 `大關開場與結尾動畫.md` 第 4 節。

**第 1 關　雪人與冰洞**（漁村・早晨）
- 故事：企鵝要從碼頭運去廣場，只有一個工人在顧。
- 開場：不加。上岸那段就是開場；這一關的教學卡最多，不要再加字。
- 過關：現有的過關台詞照用。另外在企鵝出籠的時候加兩句：

  | 誰 | 台詞 |
  |---|---|
  | 企鵝 | 嘎！（謝謝。） |
  | 家豪 | ……不用。 |

- 被抓：現有「……完了」

**第 2 關　守衛**（冰雕廣場・正午）
- 故事：企鵝被擺在冰雕旁邊讓人合照，一張十塊。廣場請了守衛。
- 開場：

  | 誰 | 台詞 |
  |---|---|
  | | （廣場的牌子：「和企鵝合照　一次十元」） |
  | 神明 | 守衛不怕滑。 |
  | 家豪 | ……那他怕什麼。 |
  | 神明 | 怕被別人撞。 |

- 過關：現有「唉……一次兩個」
- 被抓：現有「……他不是不會動嗎」

**第 3 關　薄冰**（冰晶溪谷・陰天細雪）
- 故事：這條溪是企鵝以前抓魚的地方，現在被圍起來了。冰變薄了，供桌上多一包飼料。
- 開場：

  | 誰 | 台詞 |
  |---|---|
  | 企鵝老大 | 嘎嘎。（這裡以前是我們的。） |
  | 神明 | 今天的供品多一包飼料。 |
  | 家豪 | ……我才不會為了吃改路。 |

- 過關：現有「……我只是去吃飯」。開場說不會，飼料一放就繞過去吃，現有的過關台詞剛好接上這個笑點。
- 被抓：現有「……飯還沒吞」

**第 4 關　排隊**（燈塔・金色傍晚）
- 故事：企鵝在燈塔下的碼頭排隊裝箱上船。木箱上蓋著紅色的「貨」字章，跟載走嘉欣的那輛卡車上的一樣。這是全遊戲第一次知道這些島都是同一個老闆的。
- 開場：

  | 誰 | 台詞 |
  |---|---|
  | | （一箱一箱的木箱，蓋著同一個紅色的「貨」字章。） |
  | 家豪 | ……這個章，我看過。 |
  | 神明 | 在哪？ |
  | 家豪 | 載走嘉欣的卡車。 |

- 過關：現有「……後面的不用排了」
- 被抓：現有「……有人插隊」

**第 5 關　尖峰時刻**（鐘樓・黃昏）

- 開場：

**第 6 關　全員泡湯**（燈籠夜市・極光夜）

### 5.2 駁大莖森：外婆家

時段：伐木場早晨 → 煙圈午後 → 木屋黃昏到夜。

**這一章家豪往前一步**：救了一個人類小孩。家豪討厭人類，人類把嘉欣載走了，但小紅帽不是阿土。也是在這一章，家豪第一次把狼外婆和雞舍連在一起：每天餵你、對你笑的，不一定是外婆。

**上岸**：開場動畫，見 `大關開場與結尾動畫.md` 第 5 節。

**第 1 關　伐木場**（早晨）
- 故事：伐木工照著紅漆號碼一棵一棵砍，工頭拿著懸賞單在巡邏。
- 開場：

  | 誰 | 台詞 |
  |---|---|
  | 工頭 | 懸賞單上那隻雞！抓到加菜！ |
  | 神明 | 樹會擋住他的眼睛。從後面繞。 |

- 過關：家豪「……樹還站著。」
- 被抓：家豪「……我不是木頭。」

**第 2 關　煙圈**（午後）
- 故事：午休時間，抽菸的人把菸蒂隨手彈進乾草。神明找到一個水桶。
- 開場：

  | 誰 | 台詞 |
  |---|---|
  | 神明 | 午休。菸抽完就丟地上。 |
  | 家豪 | ……整座森林是菸灰缸喔。 |
  | 神明 | 我找到一個水桶。供品升級了。 |

- 過關：家豪「……下次自己帶菸灰缸。」
- 被抓：家豪「……咳。」

**第 3 關　狼外婆的木屋**（黃昏到夜）
- 故事：小紅帽來看外婆，屋裡等她的是戴睡帽的狼。天黑以前要把她救出來。
- 開場：這一關是整章的重點，多一句。

  | 誰 | 台詞 |
  |---|---|
  | | （木屋的燈亮著。窗戶裡，外婆對著小紅帽笑。） |
  | 神明 | 小紅帽來看外婆。 |

## 6. 要跟組員對一下的地方

這些不是劇情本身，是放進遊戲時會撞到的：

1. **玩家身分有三種寫法**：霧山寫「神」，森林寫「駁大莖森之神」（`levels/forest/stage_1/battle.gd:46`），要塞寫「飄在空中的幽靈」（`levels/fort/fort_battle.gd:240`）。劇情已經用「代班」和「牆裡沒有廟」接起來，字可以不改。
2. **森林把家豪寫成「她」**：家豪是公雞，要改成「他」。
3. **羽毛顏色**（2026-11-26 已改）：選關地圖（`scripts/level_select.gd` 的 `FEATHER_COLORS`）是冰雪島青、霧山紅、森林黃、要塞紫、丹穴山金。結局（`levels/heaven/ending/ending.gd` 的 `FEATHER_COLS`）原本長出來的是赤、黃、青、白、紫，現在改成赤、黃、青、紫、金，最後長出來的那一根就是丹穴山的金色。
4. **霧山的小關說明是範本留下的**：`chapter.gd` 三個小關的說明還寫著飼料、香蕉皮、鞭炮、睡覺的守衛，實際玩的是風、雷、豪王。選關地圖上看得到，跟劇情也對不上，要請劉起佑改。
5. **南方三章不用改敵人名字**：那三章的人叫農夫、伐木工、指揮官，不叫阿土阿水也沒關係。大家都在追家豪，靠懸賞單解釋。
6. **小紅帽是人**：森林第 3 關救的是人類小孩，劇情把這件事當成家豪的一步（不是每個人都是阿土），不用改成動物。

## 7. 之後怎麼放進遊戲

這次沒有動程式，下面只是建議放的位置：

| 東西 | 放哪 | 改誰的檔案 |
|---|---|---|
| 上岸、破關 | 做成每章各一段開場、結尾動畫，怎麼接見 `大關開場與結尾動畫.md` 第 9 節。 | 各章 |
| 小關開場 | 準備階段剛開始時播，最多 3～4 句，按 Enter 跳過。播完就收掉，不常駐（照「場上對話框要少」）。 | 各章 |
| 過關、被抓 | 冰雪島和丹穴山改 `win_line`、`caught_line`；其他三章放結果卡。 | 各章 |
| 打碟那句、羽毛、懸賞 | 順序定了，直接寫在各章的結尾動畫裡，不用另外計數。 | 各章 |
| 公雞 | 選關地圖回到農莊時，看剛破完哪一章挑一句。 | 共用（`scripts/level_select.gd`） |
| 手帳一句 | `hub_journal.gd` 旅程頁的章卡 | 共用 |

時間不夠的話，照這個順序做：

2. 丹穴山第 3 關開場的「她叫嘉欣」。
3. 冰雪島第 4 關的「貨」字章、要塞第 3 關的出貨板。
4. 回農莊的公雞。
5. 其他小關的開場。
